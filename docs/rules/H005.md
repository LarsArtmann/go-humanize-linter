# H005 — manual-si-format

Detects manual SI-prefix formatting (1.5K, 2.3M) that should use
`humanize.SI`.

## Triggers

A function fires H005 when it contains:

- Division by a power of 1000 (`1000`, `1_000_000`, `1e6`, etc.)
- A string literal containing `K`, `M`, `G`, or `T` (the SI suffixes)

The detector explicitly excludes byte-unit names (`KB`, `MB`, `GB`) — those
are H001's territory.

## Real-world examples flagged

```go
if num >= 1_000_000 {
    return strconv.FormatFloat(num/1_000_000, 'f', 1, 64) + "M"
}
if num >= 1_000 {
    return strconv.FormatFloat(num/1_000, 'f', 1, 64) + "K"
}
```

## Fix

```go
return humanize.SI(num, "%.1f")  // SI with default suffix
// or
return humanize.SIWithDigits(num, 1, "", 1.0)  // custom format
```

## Suppression

```go
//nolint:gohumanize:H005
```

## Validation

- **10 real findings** across the validation sweep
- ~0% false positive rate
