# H006 — manual-ftoa

Detects manual trailing-zero stripping that should use `humanize.Ftoa`.

## Triggers

A function fires H006 when it contains the nested-call pattern:

```go
strings.TrimRight(strings.TrimRight(x, "0"), ".")
```

where `x` is some formatted number (e.g. `fmt.Sprintf("%.1f", v)`).

## Real-world examples flagged

```go
return strings.TrimRight(strings.TrimRight(fmt.Sprintf("%.1f", v), "0"), ".")
```

## Fix

```go
return humanize.Ftoa(v, 1)  // float with 1 decimal
// or
return humanize.FtoaWithDigits(v, 1, 64)
```

## Suppression

```go
//nolint:gohumanize:H006
```

## Validation

- **2 real findings** across the validation sweep
- ~0% false positive rate
