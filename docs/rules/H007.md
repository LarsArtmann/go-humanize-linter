# H007 — manual-parse-bytes

Detects manual byte-size string parsing (`"10MB"` → `bytes`) that should use
`humanize.ParseBytes`.

## Triggers

A function fires H007 when it contains **either**:

- 2+ `strings.HasSuffix` / `strings.CutSuffix` / `strings.TrimSuffix` calls
  checking byte-unit suffixes
- A `map[string]int64` literal with 2+ byte-unit keys

## Real-world examples flagged

```go
// Suffix chain
if strings.HasSuffix(s, "GB") {
    n, _ := strconv.ParseInt(strings.TrimSuffix(s, "GB"), 10, 64)
    return n * 1073741824, nil
}
if strings.HasSuffix(s, "MB") {
    n, _ := strconv.ParseInt(strings.TrimSuffix(s, "MB"), 10, 64)
    return n * 1048576, nil
}

// Multiplier map
multipliers := map[string]int64{
    "KB": 1024,
    "MB": 1024 * 1024,
    "GB": 1024 * 1024 * 1024,
}
```

## Fix

```go
return humanize.ParseBytes("10MB")  // int64
// or with error
n, err := humanize.ParseBytes("10MB")
```

## Suppression

```go
//nolint:gohumanize:H007
```

## Validation

- **2 real findings** across the validation sweep
- ~0% false positive rate
