# H003 — manual-reltime-format

Detects manual relative-time formatting that should use `humanize.RelTime`
or `humanize.Time`.

## Triggers

A function fires H003 when it contains **all** three:

1. `time.Since` or `time.Sub` call (computes elapsed time)
2. A string containing `"ago"` (relative-time suffix)
3. At least one comparison against a time threshold (`time.Minute`,
   `time.Hour`, `24*time.Hour`, etc.)

## Real-world examples flagged

```go
elapsed := time.Since(t)
switch {
case elapsed < time.Minute:
    return "just now"
case elapsed < time.Hour:
    return strconv.Itoa(int(elapsed.Minutes())) + "m ago"
}
```

## Fix

```go
return humanize.RelTime(t, time.Now(), "ago", time.Hour)
// or
return humanize.Time(humanize.TimeFormats{})  // for absolute times
```

## Suppression

```go
//nolint:gohumanize:H003
```

## Validation

- **25 real findings** across the validation sweep
- ~0% false positive rate
